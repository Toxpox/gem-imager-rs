# Security Policy

## Supported versions

Security fixes are made to the latest tagged release and to `main`.
Older releases do not receive patches; please update before reporting.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security problems.

Report privately by email to the maintainer address used across this
repository: **toxpox@outlook.com** (see `CODEOWNERS`).

Include what you can of the following:

- affected component (`gem-imager-gui`, `gem-imager-cli`, or one of the
  `gem-*` library crates) and version,
- steps or input needed to reproduce (a crafted catalog URL, image, or
  manifest is especially useful),
- your assessment of impact.

You will get an acknowledgement within a few days and a follow-up once the
issue is triaged. Fixes are released as soon as practical, and reporters
are credited in the release notes unless they prefer otherwise.
